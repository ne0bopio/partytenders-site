# PartyTenders site draft

Static website draft for PartyTenders. Palette 2 (cherry and brass) and type 3 (Federo, Cormorant Garamond, Mulish) are the current direction; the palette remains open for refinement.

## Files

- `index.html` contains the one-page site, service sections, event photos, and quote form.
- `style.css` contains the responsive layout, typography, and palette values.
- `app.js` handles the mobile menu, scroll behavior, service selections, and quote text draft.
- `assets/fotos/` contains the event photos used by the page.

The quote form prepares a text message to Danielle at the business number shown on the site. Visitors review and send it from their own messaging app; the site does not send it automatically.

This draft keeps the current photo placement for further review. It does not include the design preview controls, reference boards, or source captures.
